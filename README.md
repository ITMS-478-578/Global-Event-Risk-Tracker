# TravelGuard AI — Global Event & Risk Tracker

A desktop application that analyses any city in the world and produces a **Travel Readiness Score** (0–100) by combining real-time weather, news sentiment, currency stability, and country safety data. An AI-written travel intelligence summary is generated by Claude for each search.

---

## Features

| Feature | Details |
|---|---|
| Travel Readiness Score | Weighted composite of 4 data dimensions, 0–100 |
| Weather | Temperature (°C / °F) + sky condition via Open-Meteo |
| News sentiment | Top 5 headlines analysed by VADER NLP (no keyword lists) |
| Currency | Live exchange rate vs USD via Open Exchange Rates API |
| Safety | Country Safety Index (Global Peace Index 2023) + optional Foursquare facility counts |
| AI summary | 3-paragraph travel assessment generated by Claude |
| Analysis tab | Bar chart + radar profile + city history comparison |
| Auto-disambiguation | Geocodes the city once; passes country context to news to avoid mismatches (e.g. "Mandalay" → Myanmar, not Las Vegas) |
| Currency auto-detection | Detects local currency from the city's country code — no manual input |
| Historical log | Every search is saved to `data/city_scores.csv` |

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Global-Event-Risk-Tracker.git
cd Global-Event-Risk-Tracker
```

### 2. Create and activate a virtual environment

```bash
python3.11 -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

This installs:

| Package | Purpose |
|---|---|
| `customtkinter` | Modern dark-themed desktop GUI |
| `requests` | All HTTP API calls |
| `pandas` | CSV history read/write |
| `matplotlib` | Bar chart + radar chart |
| `python-dotenv` | Load `.env` file at startup |
| `nltk` | VADER sentiment analysis for news headlines |
| `anthropic` | Claude API client for AI summary |

On first run, NLTK will automatically download the VADER lexicon (~3 MB, cached after that).

### 4. Set your API keys

Create a `.env` file in the project root (copy the template below):

```
# Required
NEWS_API_KEY=your_newsapi_key_here
ANTHROPIC_API_KEY=your_anthropic_key_here

# Optional — adds hospital / police-station counts to the Safety card
FOURSQUARE_API_KEY=your_foursquare_key_here
```

> `.env` is listed in `.gitignore` and will never be committed.

### 5. Run the app

```bash
# From the project root with the venv active:
python src/main.py
```

## How to Use

1. Type a city name in the **Enter City Name** field (e.g. `Tokyo`, `Paris`, `Mandalay`).
2. Click **Analyze Risk**.
3. Wait 5–15 seconds while the app fetches all data sources in a background thread.
4. The **Live Tracker** tab updates with:
   - A colour-coded Travel Readiness Score (green ≥ 76, orange 51–75, red ≤ 50)
   - Four data cards: Weather, Safety, News Headlines, Exchange Rate
5. Switch to **Data Analysis Report** to see:
   - **Score Breakdown** bar chart (points each factor contributed)
   - **City Risk Profile** radar chart (raw 0–100 scores per dimension)
   - **AI Travel Intelligence** — Claude's written analysis
   - **Cities Compared** — horizontal bar chart of all cities you have analysed

## Scoring Methodology

### Weights

| Dimension | Weight | Max points |
|---|---|---|
| Safety | 30 % | 30 |
| Weather | 25 % | 25 |
| News | 25 % | 25 |
| Currency | 20 % | 20 |
| **Total** | | **100** |

### Per-dimension logic

**Weather (0–100 raw → 0–25 weighted)**  
Temperature comfort (18–25 °C = 100, extremes below 0 °C or above 38 °C = 20) averaged with sky condition (Clear sky = 100, Thunderstorm = 10, etc.).

**Safety (0–100 raw → 0–30 weighted)**  
Country-level score derived from the Global Peace Index 2023. Iceland = 99, USA = 66, Myanmar = 44, conflict zones < 20. If a valid Foursquare key is provided, hospital and police-station counts are shown in the card but do not change the numeric score.

**News (0–100 raw → 0–25 weighted)**  
VADER compound sentiment of the top 5 English headlines averaged and scaled from [−1, 1] to [0, 100]. Three-tier fallback query strategy (city + country → city only → latest) ensures results are found even for small cities.

**Currency (0–100 raw → 0–20 weighted)**  
Exchange rate (units of local currency per 1 USD) scored on a log₁₀ scale. Currencies near or stronger than USD score ~80–100; very weak currencies score lower. Uses Open Exchange Rates (no key needed).

### Failure handling

Any module that fails (network error, missing key, unknown city) returns a neutral score of **50** so a single outage does not collapse the overall result. The status bar and card text indicate unavailable data explicitly.

## City Disambiguation

The app geocodes the search term once using Nominatim (with `addressdetails=1`) before calling any other service. This resolved (lat, lon, country code, country name) is shared with all modules:

- **Weather & Safety** receive `(lat, lon)` directly — no redundant Nominatim calls.
- **News** receives the `country_name` and queries `"{city} {country}"` (e.g. `"Mandalay Myanmar"`) — prevents mismatches with hotels, casinos, or other places sharing the city name.
- **Currency** uses the `country_code` to look up the local ISO 4217 currency automatically.

Every successful search appends one row. Re-searching the same city updates its row (no duplicates).

| Column | Type | Description |
|---|---|---|

| `weather_weight` | int | Points from weather (0–25) |
| `safety_weight` | int | Points from safety (0–30) |
| `news_weight` | int | Points from news (0–25) |
| `exchange_weight` | int | Points from currency (0–20) |
| `timestamp` | string | `YYYY-MM-DD HH:MM` |

## Troubleshooting

**"Status: Error — …" after clicking Analyze Risk**  
The full traceback is printed to the terminal. Run the app from a terminal (`python src/main.py`) to see it.

**NLTK `LookupError`**  
Run once: `.venv/bin/python -c "import nltk; nltk.download('vader_lexicon')"`.

**Matplotlib glyph warnings (non-Latin city names)**  
The geocoder requests English names via `Accept-Language: en`. If warnings persist they are cosmetic and do not affect chart generation.

**`ModuleNotFoundError: No module named 'backend'`**  
Run from the project root, not from inside `src/`: `python src/main.py`.

**Exchange rate shows "no conversion needed" for a non-USD city**  
The currency is auto-detected from the country code. If the country is not in the mapping, it defaults to USD. Add the country to `COUNTRY_CURRENCY` in `backend/utils.py`.
